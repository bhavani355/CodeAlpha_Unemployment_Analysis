# CodeAlpha_Unemployment_Analysis

# Unemployment Analysis with Python

## Project Overview
This project analyzes unemployment trends in India using Python.  
The project performs data cleaning, data visualization, and statistical analysis on unemployment data.

---

## Technologies Used
- Python
- Pandas
- Matplotlib

---

## Dataset
Dataset Used:
- Unemployment in India Dataset (.csv)

---

## Features
- Data Cleaning
- Missing Value Handling
- Unemployment Trend Analysis
- State-wise Analysis
- Urban vs Rural Comparison
- Covid-19 Impact Analysis
- Seasonal Trend Analysis
- Data Visualization

---

## Graphs Included
1. Average Unemployment Rate Over Time
2. Top 10 States with Highest Unemployment
3. Urban vs Rural Unemployment Comparison
4. Covid-19 Impact on Unemployment
5. Seasonal Trend Analysis
